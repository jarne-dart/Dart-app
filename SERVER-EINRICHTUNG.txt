SERVER EINRICHTEN (einmalig, ca. 10 Minuten, kostenlos)
========================================================

Damit Konten, Online-Statistiken und öffentliche Profile funktionieren, brauchst du
einen kleinen Server. Dafür nutzt die App Supabase (kostenloser Tarif reicht).

Hinweis zum kostenlosen Tarif: Supabase pausiert Projekte, die etwa eine Woche lang
nicht benutzt wurden. Das Projekt lässt sich im Dashboard mit einem Klick wieder
starten, die Daten bleiben erhalten.


SCHRITT 1: Organisation und Projekt anlegen
-------------------------------------------
1. Auf https://supabase.com ein Konto anlegen (Anmeldung mit GitHub geht am schnellsten).
2. Beim ersten Mal verlangt Supabase zuerst eine ORGANISATION ("New organization"):
   Name beliebig (z. B. dein Name), Type: Personal, Plan: Free, dann "Create organization".
3. Danach "New project" klicken.
4. Name: dart-scorer. Region: Frankfurt (eu-central-1) oder eine Region in deiner Nähe.
5. Ein Datenbank-Passwort vergeben und irgendwo notieren. Die App braucht es NICHT.
6. "Create new project" klicken und 1 bis 2 Minuten warten.

SCHRITT 2: Datenbank vorbereiten
--------------------------------
1. Links im Menü "SQL Editor" öffnen. Dort oben links auf "+" (oder "New snippet")
   klicken und "Create a new snippet" wählen. Es öffnet sich ein leeres Eingabefenster.
   (Je nach Version steht dort statt "New query" auch "New snippet".)
2. Die Datei supabase-setup.sql in einem Texteditor öffnen (Windows: Rechtsklick,
   "Weitere Optionen anzeigen", "Öffnen mit", Editor/Notepad), ALLES kopieren
   (Strg+A, Strg+C) und in das Fenster einfügen.
3. Auf "Run" klicken. Es muss "Success" erscheinen (ohne rote Fehlermeldung).
   Das Skript darf bei Bedarf mehrfach ausgeführt werden.

SCHRITT 3: Zugangsdaten holen
-----------------------------
1. Die Project URL steht je nach Version an einer dieser Stellen:
   - Project Settings (Zahnrad) -> "Data API" -> "Project URL"
   - oben im Projekt auf "Connect" klicken
   - Die "Project ID" (Project Settings -> General) ist NUR der Teil vor ".supabase.co".
     Die URL ist dann https://<Project-ID>.supabase.co
2. Den Schlüssel findest du unter Project Settings -> "API Keys". Kopiere den
   "Publishable key" (beginnt mit sb_publishable_). Bei älteren Projekten heißt der
   passende Schlüssel "anon public" und beginnt mit eyJ. Auch der funktioniert.
   NIEMALS den "secret" oder "service_role" Schlüssel verwenden!

SCHRITT 4: In die App eintragen (eine der beiden Möglichkeiten)
---------------------------------------------------------------
A) Datei config.js im Ordner der App öffnen, die beiden Werte zwischen die
   Anführungszeichen schreiben, speichern, mit GitHub Desktop "Commit" und "Push".
   Dann gilt es automatisch auf allen Geräten.
B) Oder in der App: Einstellungen -> Konto und Server -> "Server einrichten",
   beide Werte einfügen. Das gilt dann nur für dieses Gerät.

SCHRITT 5: Konto anlegen
------------------------
In der App oben rechts auf "Anmelden" tippen, "Neues Konto" wählen, Name und eine
PIN aus 6 Ziffern eingeben. Danach werden deine Statistiken automatisch hochgeladen.
Unter "Konto" kannst du dein Profil öffentlich machen. (Charakter und Battle Pass werden vorerst nur auf dem Gerät gespeichert.) Alle öffentlichen Profile
siehst du auf dem Startbildschirm unter "Profile".


UPDATE FÜR BESTEHENDE SERVER (Charakter, Battle Pass und "The 100")
-------------------------------------------------------------------
Wenn dein Server schon läuft, musst du nur einmal das neue Skript einspielen:
1. Supabase -> SQL Editor -> "+" / "New snippet".
2. Die neue Datei supabase-setup.sql komplett kopieren und einfügen (sie enthält
   auch den alten Teil, das ist in Ordnung).
3. "Run" klicken. Es muss "Success" erscheinen. Deine Konten und Statistiken bleiben erhalten.
Ohne dieses Update funktionieren Konten wie bisher, aber "The 100" und die
Synchronisierung des Charakters sind nicht verfügbar.

"The 100": Starten kann man jeden Tag zwischen 12:00 und 23:59 Uhr (deutsche Zeit). Ab dem
Start hat man eine Stunde am Stück. Die Zeiten stehen im Skript in den Funktionen
dart100_opens und dart100_closes und können dort geändert werden.


WAS PASSIERT MIT MEINEN DATEN?
------------------------------
- Die PIN wird nur als verschlüsselter Hash gespeichert, nie im Klartext.
- Nach 5 falschen PINs ist ein Konto für 15 Minuten gesperrt.
- Die Tabellen sind von außen gesperrt. Die App darf nur die im Skript angelegten
  Funktionen aufrufen. Private Profile sind für andere nicht abrufbar.
- Öffentlich sind nur Name, Statistik und die letzten 5 Spiele, und nur wenn der
  Besitzer sein Profil öffentlich gestellt hat.


PIN VERGESSEN? (Administrator)
------------------------------
Im Supabase-Dashboard unter SQL Editor diesen Befehl ausführen (Name und PIN anpassen):

    select public.dart_admin_reset_pin('Max', '123456');

Der Benutzer meldet sich danach mit der neuen PIN an. Alle alten Anmeldungen dieses
Benutzers werden dabei beendet.

Ein Konto komplett löschen (Name anpassen):

    delete from public.dart_players where lower(name) = lower('Max');

Alle Konten und Profile ansehen:

    select name, is_public, updated_at from public.dart_players order by name;


GRENZEN
-------
- Statistiken werden nach jedem Spiel hochgeladen, wenn du angemeldet bist und Internet
  hast. Ohne Internet wird beim nächsten Spiel oder über "Jetzt synchronisieren" nachgeholt.
- Spielst du auf zwei Geräten gleichzeitig offline, gewinnt beim Abgleich die Seite mit
  den meisten Spielen.
